# ThemeLab — Website Theme & Animation Showcase Platform

An interactive React + TypeScript + Vite platform for exploring, comparing, and collecting modern website design themes, independent light/dark color modes, and interactive web animations and visual effects.

## Features

- **24 Distinct Theme Systems**: From Swiss Minimalist, Dark Luxury, Neumorphism, Bento Grid, to Cyberpunk and Editorial Typography, each applying complete visual styling to an identical landing page layout with independent light/dark modes.
- **52 Live Animations & Visual Effects**: 10 categorized families including Entrance & Exit, Typography, Layout Transitions, SVG & Shape Motion, Scroll-Driven, Microinteractions, Loading & Progress, Ambient Backgrounds, Advanced Interactive 3D, and Visual Effects & Surface Treatments.
- **My List & PDF Export**: Save favorite themes and animations into a personal collection with custom title, description, and per-item comments. Export directly to a formatted `%PDF-1.4` document with clickable deep links.
- **Monochrome Interface**: Clean black-and-white host shell with vertical sliding Sun/Moon theme toggle, responsive design for mobile and desktop, and collapsible filter toolbars.

## Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Lint and production build
npm run lint
npm run build
```

## Routes

- `/` — Main Homepage & Wireframe Gallery
- `/themes` — Theme Collection (24 Visual Systems with category filter & search)
- `/themes/:themeId` — Individual Theme Demonstrations with live Studio Controls
- `/animations` — Animation & Visual Effects Showcase (52 Live Demonstrations across 10 families)
- `/my-list` — Personal Reference Collection, item comments, and PDF Export
